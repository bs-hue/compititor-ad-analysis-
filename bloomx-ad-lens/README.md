# BloomX Ad Lens (Chrome Extension - Manifest V3)

A Chrome extension designed for **Facebook Ad Library** (`https://www.facebook.com/ads/library/*`) that automatically detects every ad card and overlays real-time financial estimates:
- **Daily Spend & Total Spend** (Low, Mid, High in Indian numbering: `₹45,000`, `₹4.5 L`, `₹2.3 Cr`)
- **Estimated Views / Impressions** (`12.4 L views`, `1.8 Cr views`)
- **Ad Type Classification Badge**:
  - 🟢 **Winner (>30 days)**: ₹2,000–4,000/day
  - 🔵 **Tested (7–30 days)**: ₹300–1,000/day
  - 🟡 **Test (<7 days)**: ₹100–300/day
- **Est. CPC (Cost Per Click)**
- **Est. Purchases** (Conversions at benchmark ₹480 CPA)
- **🎙️ 1-Click Video Script Transcription (Sarvam AI `saaras:v3`)**: Instant direct-response transcript breakdown (Hook, Problem, Mechanism, CTA) with 1-click clipboard copy
- **📥 Download Creative**: 1-click grab of HD video or image creative
- **⭐ Save to Dashboard**: 1-click sync into the central Competitor Intelligence Dashboard
- **Real Platforms Badge** (Facebook, Instagram, Messenger, Audience Network)
- **Creative Count** (e.g. `X ads use this creative and text`)
- **Library ID** with 1-click copy
- **Interactive Tooltip** with full mathematical breakdown

## 🚀 How to Install and Test in Chrome

You don't need any coding knowledge to install this. Just follow these 4 simple steps:

1. **Open Chrome Extensions Page**:
   - In Google Chrome's address bar, type:
     ```text
     chrome://extensions
     ```
     and press **Enter**.

2. **Enable Developer Mode**:
   - Look at the top-right corner of the page and toggle **"Developer mode"** to **ON**.

3. **Load Unpacked Extension**:
   - Click the button in the top-left corner that says **"Load unpacked"**.
   - A file picker window will open. Navigate to:
     ```text
     e:\Antigravity project\Competitor analysis update\bloomx-ad-lens
     ```
   - Click **"Select Folder"**.

4. **Test on Facebook Ad Library**:
   - Go to [Facebook Ad Library](https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=IN).
   - Search for any brand or advertiser (e.g., *Astrotalk*, *Mamaearth*, *Inner Calm Hub*).
   - As the ads load, you will immediately see the sleek **BloomX Ad Lens** dark cards injected above every single ad!
   - Scroll down—new ads are automatically detected and enhanced in real time!
